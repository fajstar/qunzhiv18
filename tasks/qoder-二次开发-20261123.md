# Qoder 二次开发任务：给 v18 补测试 + 清仓库垃圾

## 背景

`qunzhiv18` 是群智 v18 的后端（FastAPI 网关 376KB + 前端 25MB）。
现在的问题：**只有一个 `test_v6_code.py`，核心纯函数没有测试**；仓库里还混着备份/补丁/缓存文件。
这不影响运行，但影响可维护性与可信度。

## 硬约束（违反即失败）

1. **不要修改 `main_gateway.py` 的任何运行时逻辑**（不要动 import 顺序、不要改路由、不要改任何函数体）；
2. 不要新增第三方依赖（pytest 已装）；
3. 不要动 `static/`、`templates/`；
4. 只允许新增 `tests/`、修改 `.gitignore`、`README.md`、并删除下面点名的垃圾文件。

## 任务 A：补测试（主要）

新建 `tests/` 目录，为以下 4 个**纯函数**模块写 pytest 用例。每个模块至少 4 个用例，覆盖正常值 + 边界值：

| 模块 | 至少覆盖 |
|---|---|
| `complexity.py` | 空文本、短文本、长文本、含公式/多段落的文本 |
| `review_anchors.py` | 命中的锚点、找不到的锚点、空白/换行差异、超长引用 |
| `input_intent.py` | 不同意图的输入（如"怎么办"这类模糊输入 vs 明确课题）、空输入 |
| `privacy_scrubber.py` | 邮箱、手机号、身份证号、正常文本（不应误伤） |

要求：
- 用例名写清"测什么"，断言失败信息写清"期望 vs 实际"；
- **不允许联网**（不能调 API、不能读外部服务）；
- 跑 `python -m pytest -q tests` 必须全绿。
