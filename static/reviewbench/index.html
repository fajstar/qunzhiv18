主题图谱

对标题、关键词、摘要做中英混合分词与 TF-IDF 加权，再用 k-medoids 聚出主题簇。全部在浏览器本地计算，结果可复现。

精读对比矩阵

行是当前筛选出来的文献，列是精读时要填的四件事。表格可直接编辑，改完自动保存。

综述草稿

把主题簇和矩阵里的精读记录拼成一篇带编号引用的综述骨架。它不会替你下结论，只负责把已有材料按学术语序排好、标好引用。

— 导出后可直接粘进 Typora / Obsidian / Overleaf（Markdown）

数据与体检

导入你的真实文献、检查这个库读得够不够新、有没有重复，以及把整个库备份成一个 JSON 文件带走。

松开即可导入 .bib / .ris / .csv / .json
