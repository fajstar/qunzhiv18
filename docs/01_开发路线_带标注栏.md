## 第一部分：我们走过的路（版本谱系）

| 版本 | 一句话定位 | 留下了什么 | 没解决什么 | 我的标注 |
|---|---|---|---|---|
| **v15** | 生成：AI 团队替你预演决策 | 6 人团队讨论、联网补料、报告生成、盲评页 | 打分尺子没有区分力（AUC 0.35）；引用不能逐句核对 | |
| **v16** | 证据：把"说得对"变成"可复算" | 预注册、锚点分级、噪声底、口径纪律 | 没有产品形态；实验只到百篇级 | |
| **v18** | 产品：可核验文档问题发现 | 上传即用、带锚点清单、改法四要素、合规提醒、图表核对 | 领域知识型问题（约 51%）依赖知识库；无人工 κ | |

**要讲清的一句话**：v15 负责"想出来"，v16 负责"证明是对的"，v18 负责"让人能用"。

## 第二部分：七个关键决策（为什么这样做）

> 每行右边留空，写你自己的想法与"我能不能讲出来"。

| # | 决策 | 我们怎么选的 | 为什么（理由） | 放弃的方案 | 风险/代价 | 我的标注 |
|---|---|---|---|---|---|---|
| 1 | **定位** | 作者自查，不做"替审稿人写评审" | 评审要担责，作者只要"能改的清单" | 做 AI 审稿人 | 天花板低，但可信 | |
| 2 | **输出条数** | 16 条，可 8/20/24 | 8 条命中率 65%、16 条 53%、20 条 52%，16 是性价比拐点 | 输出 38 条"全都要" | 覆盖上限只有 42% | |
| 3 | **判定协议** | 独立模型只看"依据能否支撑主张"（三档，温度 0） | 让"生成"和"判定"分开，减少自证 | 让生成模型自己打分 | 成本 +1 次调用 | |
| 4 | **锚点闸门** | T1 连续≥40 字 / T2 部分逐字放行 / T3 不进清单 | 承诺"每条都能点回原文" | 不设闸门，宁多勿少 | 会漏掉一些真问题 | |
| 5 | **召回路数** | 六方向补漏 + 主张审计（R1+R2） | 实测 +7.24pt（CI ±1.2，52/60 全胜） | 只靠一次生成 | 误报 +4pt | |
| 6 | **不用多智能体** | 5 角色实测 **−3.3pt**，弃用 | 同模型角色会"同错"，异构只改措辞 | 5 角色 + 投票 | 少了一个"听起来高级"的卖点 | |
| 7 | **建议四要素** | 动作受类别约束 + 对象锚定 + 验收可检查 + 可忽略条件 | 防"改错方向"、防"过度修改" | 只给"建议补充实验" | 生成长度变长 | |

## 第三部分：数字从哪来（口径纪律）

| 指标 | 定义（必须能背） | 我们的数 | 容易讲错的地方 | 我的标注 |
|---|---|---|---|---|
| **覆盖率** | 命中的不同人类问题点 ÷ 该篇问题点总数 | 25.6%（60 篇） | 不是"正确率"；分母是人类问题点（≈38 条/篇） | |
| **单条命中率** | 命中数 ÷ 我们输出条数 | 57.4% | 说"10 条里 5.7 条人类也提了"最直观 | |
| **误报率** | 判定"不支撑"的条目占比 | 21.4% | 依赖判定协议，要报区间 20–24% | |
| **锚定率** | T1+T2 占比 | 99% | 不是"准确率"，是"能点回原文的比例" | |
| **人类-人类重合** | 一位审稿人的问题被另一位覆盖的比例 | 28.9% | 用来解释"为什么 25% 不算低" | |
| **结构上限** | 输出名额 ÷ 人类问题点 | 16÷38≈42% | 上限不等于满分 | |
| **候选池上限** | 每篇最多能生成多少条带依据的问题 | 18.8 条/篇 | 这才是覆盖率真正的瓶颈 | |
| **bootstrap CI** | 按篇重抽样 1000 次求均值区间 | A5−A0: +7.24pt [6.08, 8.48] | 不要说"p<0.05"，我们说 CI 与胜负数 | |

## 第六部分：术语表（讲之前先背熟）

| 术语 | 白话解释 |
|---|---|
| 锚点 / T1 T2 T3 | 问题必须带一段原文；T1 是连续 ≥40 字逐字，T2 是部分逐字，T3 是没依据（不进清单） |
| heldout | 换一批没见过的论文测，检验有没有"背答案" |
| 配对比较 | 同一篇上比两个方法，而不是比平均值 |
| 误报 | 我们说有问题，但原文其实不支持 |
| 单条命中率 | 我们说的每一条，有多少被人也提过 |
| 可忽略条件 | 告诉作者"什么情况下这条不用改"，防过度修改 |
| 无编造闸门 | 建议里的数字必须在原文出现，否则自动删 |

## 第八部分：答辩三句底稿（背下来）

1. **我们是做什么的**：把论文里"能用证据核对的问题"，40–80 秒变成一份能照着改的清单。
2. **凭什么可信**：每条都点得回原文（锚定 99%）；建议里的数字必须在原文出现（无编造闸门）；换一批论文结论不变（独立 120 篇 +10.17pt）。
3. **边界在哪**：需要领域知识的问题（约 51%）靠知识库；图内数值不读；结论必须人确认。
